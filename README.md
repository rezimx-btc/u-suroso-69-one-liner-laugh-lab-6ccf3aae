## How to run

```sh
python3 main.py
```

Requires Python 3.13 (stdlib only — no third-party packages, no file I/O,
no network). Prints exactly one line to stdout and nothing else.

## The entry

> Hypothesis: my toaster loves me. Result: it fired my bagel into the ceiling fan, which returned it straight to my forehead.

## Why it fits the brief

The line is framed as a lab experiment — a stated hypothesis ("my toaster
loves me") tested on the most mundane kitchen appliance, which then goes
sideways in a specific, visual way: the bagel is launched into the ceiling
fan and comes straight back to the experimenter's forehead. One concrete
detail (the toaster), a surprise twist in the second half (the appliance
fights back), and no clichés — no "I told my wife" setup, no generic
programmer joke about bugs. One line, well under 200 characters.
